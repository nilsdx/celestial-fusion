# Millenium Photon Core

Millenium Photon Core (commonly abbreviated MPC) is a rare tool that is used in various item combinations in [The Phantastic Bazaar](/quests/the-phantastic-bazaar) for endgame items. It is the signature drop from [The Phantasmal Dimension](/quests/the-phantasmal-dimension), but can also be dropped in a few other quests.

## The Phantastic Bazaar

Millenium Photon Core are required in various recipes that can be checked on [The Phantastic Bazaar](/quests/the-phantastic-bazaar) page.

## Availability
